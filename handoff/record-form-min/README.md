# 最小版验收记录形态 · 使用说明（2026-11-26）

> 配套建议：`handoff/n5-record-form-1128.md` §4「最小版」。本目录是可直接用的模板，不是证据，也不含任何产品数据。
> 目标：**读者自己填、填完即封存、区间逐字抄屏、零求助显式记 0。** 不装新工具、不改产品码、不改栈。

## 目录

| 文件 | 谁用 | 用途 |
|---|---|---|
| `reader-sheet.md` | 读者 | 电子记录纸；读者自己在**自己的**会话/设备里填 |
| `question-log.md` | 主持人 | 零求助提问日志；当场逐行追加，收场由读者确认 |
| `clock.html` | 双方 | 大字参考钟（时:分:秒 + 日期 + 时区），供抄「开场 / 收场」时刻 |
| `seal.ps1` | 主持人 | 收场封存：置只读 + 算 sha256 + 写清单 |

## 场次流程（六步）

1. **开场前（T-10m）**
   - 把 `reader-sheet.md` 拷一份成本场专用：`reader-sheet-<日期>-<读者代号>.md`，**拷到读者能编辑的位置**（读者的设备；或在本机新建一个只有读者用的 Windows 账户/浏览器 profile）。
   - 打开 `clock.html`，放在**录制范围内看得见**的位置（录整屏时放屏幕角落；只录窗口时，让读者用自己的手机或任务栏时钟对时，并把读到的时刻抄进申请书）。
   - 主持人打开 `question-log.md`，改成 `question-log-<日期>.md`。

2. **开场（T0）**
   - 读者在申请书「一、开录时钟」里抄下当下时刻（**抄，不算**）。
   - 主持人开始录屏。**录屏原件不转码、不重封装**，采集出来什么样就存什么样。

3. **场中**
   - 读者填写申请书二至五节；**区间一律逐字抄检索框**，不换算、不补零、不改格式。
   - 每发生一次提问（含事务性），主持人当场在日志追加一行。

4. **收场**
   - 读者在申请书「七、声明」签名并抄收场时刻；在提问日志末行亲写「本场主持人回答我 N 次，其中内容性 M 次」（N=0 也要写）。
   - 停录屏。

5. **封存**
   ```
   powershell -File .\seal.ps1 -Path ..\evidence\<场次目录>\reader-sheet-<日期>-<代号>.md,..\evidence\<场次目录>\question-log-<日期>.md
   ```
   - 脚本把这些文件置只读并输出 `seal-manifest.txt`（`<sha256>  <文件名>`）。
   - 把 `seal-manifest.txt` 连同录屏、CSV、截图一起归档；**清单本身不参与自己的哈希**。

6. **归档后**
   - 未来若要对外锚定，把 `seal-manifest.txt` 的哈希写进一次 commit 或发布说明（可选，不属最小版）。

## 这套模板补了什么、没补什么

| N5 缺口 | 最小版 | 说明 |
|---|---|---|
| 区间纸张值 | **补上** | 申请书直接抄屏幕值，誊录环节不存在 |
| 零求助「没记」 | **补上「记了 0」** | 有没有求助仍只能人证，但「没记」变成「明确记 0 并签」 |
| 实际起止 | 部分 | 申请书里是可读时刻；机器锚点仍是登录行 + 录屏 mtime/时长 |
| 截图 / 签名件 | 不变 | 仍须读者当场截图、当场签名 |
| E3 上限 | **不变** | 没有独立真人批准人，是数据/种子问题，换记录形态抬不动 |

## 注意

- **不要让主持人代填申请书任何一格**，包括「你没提问题吧」这类引导。填不完全就留空并注明「未填」。
- 申请书里**不要出现答案**（对象、主键、区间都由任务纸与屏幕决定，模板只留空位）。
- 模板文件本身不要写进证据目录后再编辑；一旦开始填就是本场原件。
